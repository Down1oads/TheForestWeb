# TheForestWeb

An unofficial browser port of *The Forest* (single player, runs entirely in your browser).

- Ported by Down1oads.
- The game, its art, audio and code belong to its original developers (Endnight Games). This is a fan port, not affiliated with or endorsed by them. If you are the owner and want it taken down, open an issue and it will be removed.
- Graphics are deliberately reduced (no shadows, simple lighting, small textures) so the game fits in a browser; game code and physics are the original.
- Known gaps: no audio yet, no multiplayer, no Steam features. Use a desktop browser with a GPU; the first load downloads about 750 MB, later visits use the browser cache where available.
